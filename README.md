# MAS Aquarium Studio

Public interactive prototype for Micro Aquatic Shop.

Open https://huyth96.github.io/mas-aquarium-studio/planner/

## Build in 2D, explore in 3D

- The default builder uses the illustrated 2D aquarium. Drag plants, animals and hardscape directly; Measured map provides a top-down footprint.
- The mobile workspace fits the screen. One-tap Add places an object and opens large Move, Size and depth/direction controls. Objects selects individual items, including those behind plants. Compact product rows keep their Add buttons visible.
- Animals remain still while editing. Their stored positions and direction are used consistently by drag, touch controls, Undo, saves and share links.
- View in 3D opens the same layout as an animated scene. Return to 2D preserves the layout; only changes to lighting and water settings are carried back from the viewer.
- Desktop users can drag catalogue products into the aquarium. Named projects, sharing, image export and the mobile Workspace options remain available.
- The catalogue includes four plants, thirteen animal types and four hardscape illustrations. Seventeen linked MAS products have dated AUD guide prices and 34 verified variant mappings. Review product options and purchase quantities separately from layout counts.
- Stone and wood remain in-store consultation items and are excluded from the online cart. Final prices, stock, shipping and checkout are confirmed at MAS.

## Prototype limits

This is a visual planning prototype, not a physical simulator or stocking/compatibility adviser. Illustrations do not claim exact delivered dimensions. Accurate product calibration needs measured assets from the shop.

Guide prices were checked on 8 September 2026. Purchase choices are session-only; named aquarium layouts are stored in the visitor's browser and can be shared by scene link. Physical-phone performance has not been measured.

Most 2D aquarium sprites are AI illustrations; the gold mystery snail uses a cutout from a MAS product photo. The 3D viewer uses simplified procedural models. This repository contains only the compiled prototype and does not change the MAS Shopify theme.
